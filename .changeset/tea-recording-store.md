`@demlik/tea/do`: `doEventSourcedStore` takes `recording: { provenance }`. A log it starts is written as a recording: an `init` frame for each boot, carrying `provenance`, and a `step` frame for each applied Msg, each with the State after it and the Cmds the engine started for it, stored whole or as a delta against the frame before it. Restore folds the step frames and skips the init frames, and `snapshotEvery` counts Msgs only. A log already written as bare messages keeps being written that way, and a recording stays one without the option. A recording whose last frames cannot be rebuilt does not stop restore, since the Msgs and the snapshot rebuild the State: the next frame is written whole as a new basis, and `onRecordingBreak` (default: a `console.warn`) hears which frames are broken. Read it with `doEventLogReader(...).readFrames`. A cell is a recording cell only when its text starts with a `tea` field of `recording/<version>`, so a store without `recording` restores the bare Msgs it wrote before, even a Msg whose own first field is `tea`. The one collision left is a Msg whose first field is `tea` with a value that starts `recording/`: it is read as a recording cell and refused. Restore reads only each cell's Msg, so a step whose evidence cannot be read still restores, and `onRecordingBreak` hears the frame; a cell that is not JSON still refuses the restore.

**Additive (declaration only):** `EventSourcedOptions` gains the optional fields `recording` and `onRecordingBreak`, and `@demlik/tea/do` exports the type `RecordingBreak`.
