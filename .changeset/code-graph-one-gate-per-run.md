A run now takes one gate. `code-graph` answers with the first mode its flags reach, so `--unreachable --ci --boundaries` ran only the boundary gate and could exit 0 over a new dead export. Two of `--layers`, `--boundaries`, `--comments`, `--collapse` and `--unreachable` with `--ci`, `--write-ceilings`, `--accept-crossings`, `--accept-dead` or `--migrate-ceilings`, and `--env-keys` or `--hexagon` beside a gate, plain `--ci` or `--accept-smells`, now exit 2 with one line naming them, before any ledger or ceilings file is read.

**A command that names two gates now fails on upgrade.** Split it into one command per gate. A `--ci` riding one named gate, a gate run alone and two report flags such as `--cycles --kinds` behave as before.
